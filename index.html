AVES ENCRYPT

Secure Message Tool
V1 • BROWSER-BASED • AES-GCM
Security model:
AVES Encrypt uses the browser's Web Crypto API with authenticated AES-GCM (256-bit). A unique random salt and IV are generated for every encryption. The password is converted into an encryption key with PBKDF2-SHA-256 using a high iteration count. No message or password is sent to a server by this page.
